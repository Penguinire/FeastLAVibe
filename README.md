# Feast & Vibe 🍽️🎉

## About the Project

Feast & Vibe is an Android application I developed to make it easier for people to discover restaurants, explore places to eat and find events around them.

The main idea behind the app is to bring restaurant discovery and event exploration together in one place. Instead of having to search through multiple platforms, users can use Feast & Vibe to find places, view useful information, save their favourite restaurants and explore events.

The app is mainly aimed at young adults, but anyone interested in discovering restaurants and events can use it.

## Main Features

- **User Authentication:** Users can register and log in to their accounts.
- **Restaurant Discovery:** Browse and search for restaurants and food places.
- **Map Integration:** View restaurant locations and explore nearby places.
- **Favourites:** Save restaurants and access them later.
- **Restaurant Details:** View information about restaurants, including available ratings and reviews.
- **Events:** Explore events and view additional event information.
- **Weather Information:** View temperature information alongside the map experience.
- **User Profile:** Manage profile information and personal details.
- **Settings:** Control the notification preference.
- **Push Notifications:** Receive notifications through Firebase Cloud Messaging.
- **Offline Favourites:** Saved favourites remain available even without an internet connection, including after closing and reopening the app.

## Recent Updates

I have recently made several improvements to the application, mainly focusing on functionality and making the app more practical to use.

Some of the latest changes include:

- Improved offline functionality for the favourites feature using local storage.
- Added synchronisation of saved favourites with Firebase Firestore when connectivity is available.
- Added a Settings screen with a notification preference.
- Integrated Firebase Cloud Messaging for push notifications.
- Added Android notification permission handling.
- Tested notification delivery successfully using Firebase Console.
- Added GitHub Actions to automatically run unit tests and build the Android application.
- Continued improving the application's navigation and overall functionality.

## Download and Install the APK

You can download the latest successfully built version of Feast & Vibe directly from GitHub.

**[Download Feast & Vibe APK](https://github.com/Penguinire/FeastLAVibe/actions/workflows/android.yml)**

To download the application:

1. Open the download link above.
2. Select the latest successful workflow run (green tick).
3. Scroll down to the **Artifacts** section.
4. Download `Feast-Vibe-APK`.
5. Extract the downloaded ZIP file.
6. Open `app-debug.apk` on your Android device.
7. If prompted, allow installation from that source.
8. Install the application and open Feast & Vibe.

Please note that GitHub only provides an APK artifact when the automated build completes successfully.
